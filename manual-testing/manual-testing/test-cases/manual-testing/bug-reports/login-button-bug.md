# BUG-001 — Login button does not respond with valid credentials

## Summary

Login button does not respond when the user enters valid credentials.

## Environment

- Browser: Google Chrome
- Operating System: Windows 11
- Environment: Test
- Build: 1.0.0

## Preconditions

- User has a registered account.
- User is on the Login page.

## Steps to Reproduce

1. Open the Login page.
2. Enter a valid email address.
3. Enter a valid password.
4. Click the Login button.

## Expected Result

User should be successfully logged in and redirected to the homepage.

## Actual Result

Nothing happens after clicking the Login button.

## Severity

High

## Priority

High

## Reproducibility

5/5 — Always reproducible
